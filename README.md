### Чем владею

- **Архитектура:** микросервисы, Clean Architecture, DDD, event-driven, CQRS
- **Highload:** горизонтальное масштабирование, кэширование, партиционирование и шардирование, батчевая обработка, rate limiting
- **Распределённые системы:** Transactional Outbox, Saga, идемпотентные консьюмеры, гарантии доставки, CAP, eventual consistency
- **Надёжность:** retry с экспоненциальным backoff, circuit breaker, таймауты, graceful shutdown
- **Базы данных:** индексы и EXPLAIN, уровни изоляции транзакций, блокировки, миграции без даунтайма
- **Наблюдаемость:** метрики, структурированные логи, распределённые трейсы, дашборды и алерты
- **Качество:** unit- и интеграционные тесты, линтеры, CI/CD
